**Bangkok meetup · 2022**

**.NET 6 + WebAssembly + Avalonia** for real cross-platform apps (desktop, mobile path, WASM).

### Deck themes
- WASM use cases: desktop ports, games, shared backend code, less JS
- .NET 6: AOT, trimming, single-file
- Blazor vs full UI frameworks; Avalonia vs MAUI readiness
- Happen Space product context
- Practical pain: shaders, threading, missing libraries, hiring

Takeaway: Avalonia + .NET WASM was production-usable while MAUI still felt early.
